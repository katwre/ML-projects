# ML-projects

A collection of my machine learning mini-projects exploring deep learning and data science methods, including:

1. **Autoencoders** for scRNA-seq dimensionality reduction and data imputation (autoencoder_scRNA-seq)

2. **Convolutional Neural Networks (CNNs)** for image classification tasks based on chest X-rays (CNN_and_TransferLearning_Xray)

3. **Transfer learning** for image classification tasks using pre-trained models (CNN_and_TransferLearning_Xray)

4. **Survival analysis** with clinical and gene expression data (survival_analysis_multiple_myeloma)

5. Minimal **federated learning workflow** to compute a weighted mean of the per-site gene variances to identify the most variable genes (federated_learning_minimal)

6. Variational autoencoder (**VAE**) approach to mitigate batch effects in scRNA-seq using **federated learning** simulations (federated_learning_scRNA-seq)

7. minimal **Retrieval-Augmented Generation** (RAG): sentence-transformers + Google's FLAN-T5 and also applied in bioinformatics (RAG_minimal)

8. minimal Bayesian State Space Model (SSM_minimal)

9. Variational autoencoder (**VAE**), minimal **BERT language model/transformer**, semi-supervised **NMF** and regression-based methods (lasso, ridge regression, elastic net) for the cell type deconvolution (VAE_NMF_Transformer_regression_cfDNA)

10. **LLM-powered SPARQL Bioinformatics Assistant** that uses a language model to turn biology questions into SPARQL queries, run them on UniProt/OMA/Bgee, and explain the results (llm_biodata)

11. From-scratch Graph Neural Networks (**GNNs**) for spatial transcriptomics (GNN_spatialomics)
